# בניית צוות אלמוגי

הסקריפט `backend/almogi/build_team.py` **פותח את הצוות במערכת** ומגדיר בו את האנשים, סוגי המשמרות, היציאות, הכללים הקבועים וגבולות העומס.

**הוא לא משבץ משמרות.** את השיבוץ בונים אחר כך מהמסך של המנהל, כמו בכל צוות אחר.

| קובץ | מה יש בו |
|---|---|
| `backend/almogi/roster.py` | כל אנשי הצוות: תפקיד, מבנה יציאות, קבוצה, מעמד והסמכה לחפיפה |
| `backend/almogi/build_team.py` | הסקריפט שבונה את הצוות ושולח אותו לשרת |

---

## איך מריצים

הסקריפט נמצא בתוך אימג' ה-backend בתיקייה `/app/almogi`. הוא משתמש רק בספריות שמגיעות עם Python.

מתיקיית השורש של הפרויקט בונים את האימג' מחדש:

```bash
docker build -t pakash-backend ./backend
```

נכנסים לקונטיינר (`<container>` = השם מהעמודה NAMES ב-`docker ps`):

```bash
docker exec -it <container> bash
```

בודקים מה ייבנה, בלי לשלוח כלום:

```bash
cd /app/almogi
```

```bash
python build_team.py --dry-run
```

בונים את הצוות:

```bash
python build_team.py --team-password <סיסמה>
```

אפשר להריץ גם מהמחשב, בלי להיכנס לקונטיינר, מול שרת שרץ. למשל מול ה-sandbox:

```bash
python3 backend/almogi/build_team.py --url http://localhost:8100 --team-password <סיסמה>
```

אם כבר קיים צוות באותו שם, הסקריפט עוצר ולא פותח צוות נוסף.

---

## כל הפרמטרים

| פרמטר | ברירת מחדל | הסבר |
|---|---|---|
| `--team-password` | — | הסיסמה של מנהל הצוות החדש, לפחות 6 תווים (חובה, חוץ מ-`--dry-run`) |
| `--name` | `אלמוגי` | שם הצוות |
| `--admin-password` | מתוך `PAKASH_ADMIN_PASSWORD` או `PAKASH_SETTINGS_PASSWORD`, אחרת ברירת המחדל של המערכת | סיסמת קונסולת המפעיל (`/admin`) |
| `--url` | `http://localhost:8000` | כתובת השרת |
| `--dry-run` | כבוי | רק להדפיס, בלי לשלוח לשרת |
| `--out profile.json` | — | לשמור את הצוות שנבנה לקובץ JSON |
