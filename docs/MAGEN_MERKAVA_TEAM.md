# בניית צוות האלחוט — מגן מרכבה

הסקריפט `backend/magen_merkava/build_team.py` **פותח את הצוות במערכת** ומגדיר בו את כל מה שצריך כדי לשבץ:
האנשים, סוגי המשמרות, התקינה, האילוצים והכשירות.

**הוא לא משבץ משמרות.** את השיבוץ בונים אחר כך מהמסך של המנהל, כמו בכל צוות אחר.

| קובץ | מה יש בו |
|---|---|
| `backend/magen_merkava/roster.py` | כל האנשים מהגיליון ומלוח המשמרות, עם ההערות |
| `backend/magen_merkava/build_team.py` | הסקריפט שבונה את הצוות ושולח אותו לשרת |

---

## איך מריצים

הסקריפט נמצא בתוך אימג' ה-backend בתיקייה `/app/magen_merkava` ומדבר עם השרת שרץ באותו קונטיינר.
הוא משתמש רק בספריות שמגיעות עם Python, אז לא צריך להתקין כלום.

### 1. לבנות את האימג' מחדש

אחרי `git pull` צריך לבנות את האימג' מחדש, כדי שהסקריפט ייכנס אליו. מתיקיית השורש של הפרויקט:

```bash
docker build -t pakash-backend ./backend
```

ואז להרים את הקונטיינר כמו שמרימים אותו תמיד (עם מסד הנתונים).

### 2. להיכנס לקונטיינר

למצוא את שם הקונטיינר:

```bash
docker ps
```

להיכנס אליו (`<container>` = השם מהעמודה NAMES):

```bash
docker exec -it <container> bash
```

> אם אין `bash`, להשתמש ב-`sh`.

### 3. לבדוק מה ייבנה (לא שולח כלום)

```bash
cd /app/magen_merkava
```

```bash
python build_team.py --dry-run
```

מודפסים כל סוגי המשמרות, כל האנשים עם התא והכשירות שלהם, מי לא פעיל, וכל הכללים.

### 4. לבנות את הצוות

```bash
python build_team.py --team-password <סיסמה> --start 2026-11-04
```

- `--team-password` — הסיסמה שתהיה למנהל הצוות החדש. **חובה.**
- `--start` — היום הראשון של הקריאה. ממנו נקבע מתי נגמרות "72 השעות הראשונות".

בסוף יודפס:

```
נפתח הצוות 'אלחוט — מגן מרכבה' (...).
```

### 5. להיכנס לצוות

נכנסים לאתר, בוחרים את הצוות **"אלחוט — מגן מרכבה"** במסך הכניסה ומזינים את הסיסמה מ-`--team-password`.
משם בונים את השיבוץ.

## כל הפרמטרים

| פרמטר | ברירת מחדל | הסבר |
|---|---|---|
| `--team-password` | — | הסיסמה של מנהל הצוות החדש (חובה, חוץ מ-`--dry-run`) |
| `--start` | — | תאריך תחילת הקריאה (`YYYY-MM-DD`). בלעדיו "72 שעות ראשונות" נשאר רק ככלל במילים |
| `--name` | `אלחוט — מגן מרכבה` | שם הצוות |
| `--admin-password` | מתוך `PAKASH_ADMIN_PASSWORD` או `PAKASH_SETTINGS_PASSWORD` של הקונטיינר, אחרת `010802` | סיסמת קונסולת המפעיל (`/admin`) |
| `--url` | `http://localhost:8000` | כתובת השרת. מתוך הקונטיינר — אין צורך לשנות |
| `--full-emergency` | כבוי | להשאיר פעיל גם את מי שמגיע "רק בחירום מלא" |
| `--dry-run` | כבוי | רק להדפיס, בלי לשלוח לשרת |
| `--out profile.json` | — | לשמור את הצוות שנבנה לקובץ JSON |

## מה נבנה בצוות

### סוגי משמרות

לכל תא: **יום 08:00-20:00** ו-**לילה 20:00-08:00**, כל ימות השבוע, לפי התקינה בלוח (בלי כחול):

| תא | אנשים במשמרת | משמרות |
|---|---|---|
| א', ת', מ', ח', ר' | 3 | יום + לילה |
| ד', ע', מרחקים | 2 | יום + לילה |
| התרעה | 6 | יום + לילה |
| ס' (סיבוב) | 3 | לילה — רק בלילה הראשון, אחר כך עוברים לתא הבא |
| רוחב | 2 | יום |
| חפיפות | 3 | יום (משמרת חפיפה) |

כל משמרת פתוחה רק לאנשי התא שלה. אנשי ס' רשאים גם במשמרות של התא הבא שלהם.

### אנשים

- **תא** — לפי לוח המשמרות. אם הגיליון רשם תא אחר, זה מופיע בהערות.
- **סוג שירות** — מילואים, הצ"ח, אע"צ, חובה/קבע.
- **כשירות** — הנמוכה מבין "כשירות" ו"רמה" בגיליון: 1 = גבוה, 2 = בינוני, 3 = חלש. מי שיובל לא מכיר — "חלש".
- **הערות** — ההערה של יובל כמו שהיא, הכשירות והרמה המקוריות, המקור, ו"לבדוק" כשהשם לא היה ברור בתמונה.
- **אין יציאות** — כולם זמינים כל השבוע (קריאה).

### מי לא פעיל

מסומנים כלא פעילים מהיום (אפשר להחזיר מהמסך בכל רגע):
- חסומים: עידו בבאי, סיני קלימי
- לא בפול / כרגע במקום אחר: ניקאן מוטיעי, מאור חכימיאן, ישר פשאי, דנה סימאן, מואיס אליאסיאן, רועי מרדי, מואיס סולימאן
- אי זמינות ארוכה: ציון קלימי, יוסף יחייב, נוי בבאי
- מעיין: דור עוז, מעוז בר שמעון, שני יחזקליאן
- לא זמינים: קרן ארפנשאד (הריון מתקדם), הילה אברהם פור (אירוע אישי)
- סרבנית: נאזנין סעידיאן
- רק בחירום מלא: עומר שירזי (פעיל אם מריצים עם `--full-emergency`)
- 72 שעות ראשונות: משה כהן, עדן קשני, אהרון ישעיהו — לא פעילים מ-3 ימים אחרי `--start`

דולב אושר אליאס (מפקדת שמע) לא בלוח, ולכן לא נכנס לצוות.

### אילוצים קבועים

- **בלי לילות:** תומר אברהמי, אור אדיבי, לימי רובין
- **רק שישי-שבת:** איתי בבאי

### כללים (במילים — המערכת מתרגמת אותם בשיבוץ)

חובה:
- כל אחד עובד רק במשמרות של התא שלו.
- לפחות 12 שעות מנוחה בין משמרות.
- ס' רק בלילה הראשון, ואחריו כל אחד מאנשי הסיבוב עובר לתא הבא שלו.
- מי שלא מוסמך, לא מוכר או ברמה 3 — רק עם מישהו מנוסה מהתא באותה משמרת.
- 72 השעות הראשונות בלבד — למשה כהן, עדן קשני, אהרון ישעיהו.

העדפה:
- לפחות אחד ברמה גבוהה בכל משמרת.
- כל אחד נשאר באותו סוג משמרת (יום או לילה).
- חלוקה שווה בתוך התא.
- להעדיף לא לשבץ את מי שלא בטוח שיגיע (נעם בלס) או מגיע בתנאי (אדיר סמהי).

### מדיניות

- מנוחה מינימלית 12 שעות, עד 14 ימים ברצף, עד 84 שעות בשבוע.
- לכל היותר חלש אחד במשמרת.

## איך משנים

| רוצה לשנות | איפה |
|---|---|
| אדם השתחרר / נחסם / הצטרף / עבר תא | `roster.py` — השורה שלו (`cab`, `flags`, `note`) |
| תקינה בתא | `CABS` בראש `build_team.py` |
| שעות המשמרות | `DAY_START`, `NIGHT_START` בראש `build_team.py` |
| כללים | `build_rules()` ב-`build_team.py` |

אחרי שינוי צריך לבנות את האימג' מחדש (שלב 1), או להעתיק רק את הקובץ לקונטיינר:

```bash
docker cp backend/magen_merkava/roster.py <container>:/app/magen_merkava/roster.py
```

> הסקריפט **פותח צוות חדש** בכל הרצה. כדי לבנות מחדש — למחוק את הצוות הקודם מקונסולת המפעיל (`/admin`),
> או להריץ עם `--name` אחר. שינויים קטנים עדיף לעשות ישר במסך הצוות.

| `אין חיבור לשרת ב-http://localhost:8000` | השרת לא עלה בקונטיינר. לבדוק `docker logs <container>` |

| `חסר --team-password` | להוסיף `--team-password <סיסמה>` |
