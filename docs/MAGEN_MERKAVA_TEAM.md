# בניית צוות האלחוט — מגן מרכבה

הסקריפט `backend/magen_merkava/build_team.py` **פותח את הצוות במערכת** ומגדיר בו:
האנשים, התפקיד, סוגי המשמרות, התקינה, הכשירות והסבב, ומי לא זמין כלל.

**הוא לא משבץ משמרות.** את השיבוץ בונים אחר כך מהמסך של המנהל, כמו בכל צוות אחר.

| קובץ | מה יש בו |
|---|---|
| `backend/magen_merkava/roster.py` | כל אנשי האלחוט מהאקסל של הפול: תא, סוג שירות, כשירות, ומי לא זמין |
| `backend/magen_merkava/build_team.py` | הסקריפט שבונה את הצוות ושולח אותו לשרת |

---

## איך מריצים

הסקריפט נמצא בתוך אימג' ה-backend בתיקייה `/app/magen_merkava` ומדבר עם השרת שרץ באותו קונטיינר.
הוא משתמש רק בספריות שמגיעות עם Python, אז לא צריך להתקין כלום.

### 1. לבנות את האימג' מחדש

אחרי `git pull` צריך לבנות את האימג' מחדש, כדי שהסקריפט ייכנס אליו. מתיקיית השורש של הפרויקט:

```bash
docker build -t pakash-backend ./backend
```

ואז להרים את הקונטיינר כמו שמרימים אותו תמיד (עם מסד הנתונים).

### 2. להיכנס לקונטיינר

למצוא את שם הקונטיינר:

```bash
docker ps
```

להיכנס אליו (`<container>` = השם מהעמודה NAMES):

```bash
docker exec -it <container> bash
```

> אם אין `bash`, להשתמש ב-`sh`.

### 3. לבדוק מה ייבנה (לא שולח כלום)

```bash
cd /app/magen_merkava
```

```bash
python build_team.py --dry-run
```

מודפסים כל סוגי המשמרות וכל האנשים עם התא, הכשירות והסבב שלהם.

### 4. לבנות את הצוות

```bash
python build_team.py --team-password <סיסמה> --start 2026-11-04
```

- `--team-password` — הסיסמה שתהיה למנהל הצוות החדש. **חובה.**
- `--start` — היום הראשון של הקריאה. סבב ה-12/2 נספר מיום ראשון שלפניו. בלי `--start` — היום.

בסוף יודפס:

```
נפתח הצוות 'אלחוט — מגן מרכבה' (...).
```

### 5. להיכנס לצוות

נכנסים לאתר, בוחרים את הצוות **"אלחוט — מגן מרכבה"** במסך הכניסה ומזינים את הסיסמה מ-`--team-password`.
משם בונים את השיבוץ.

## כל הפרמטרים

| פרמטר | ברירת מחדל | הסבר |
|---|---|---|
| `--team-password` | — | הסיסמה של מנהל הצוות החדש (חובה, חוץ מ-`--dry-run`) |

### אנשים

הרשימה נבנתה מ**האקסל של כל הפול**: רק מי שהדיסציפלינה שלו "אלחוט", מגיליונות התאים
(הגיליון "כל הפול - לא עדכני" לא נקרא, ואנשי כחול לא נכנסים). 84 אנשים.

- **תפקיד** — כולם `אלחוט`.
- **תא** — לפי הגיליון שבו האדם מופיע. אנשי ס' משויכים גם למשמרות של התא הבא שלהם.
- **סוג שירות** — מעמודת "מקור": מילואים, סדיר (כולל חובה וקבע), אע"צ, הצ"ח.
- **כשירות** — הנמוכה מבין "כשירות" ו"רמה": 1 = גבוה, 2 = בינוני, 3 = חלש. "עוד לא הוסמכה" = חלש.
  בגיליונות שאין בהם כשירות (התרעה, רוחב, חפיפות) היא נלקחה מגיליון האלחוטנים.
- **הערות** — ריקות, חוץ ממי שלא זמין (ראו "אילוצים").

### סבב

| מי | סבב |
|---|---|
| סדיר (כולל חובה וקבע), אע"צ, הצ"ח | **12/2** — ראו למטה |
| מילואים | **עד 4 ימים בשבוע** |

**איך עובד ה-12/2:**
- 12 ימים בבסיס מיום ראשון, **יוצאים בשישי ב-08:00** וחוזרים **בראשון ב-12:00**, ומשתלבים במשמרות.
- בפועל: עובדים עד משמרת הלילה של חמישי (שנגמרת בשישי ב-08:00), לא במשמרת היום של שישי, לא בשבת,
  לא במשמרת היום של ראשון (חוזרים באמצע) — וחוזרים למשמרת הלילה של ראשון.
- שתי קבוצות בהפרש שבוע: חצי מכל תא בקבוצה א' וחצי בקבוצה ב', כך שכל סוף שבוע יוצאת חצי — וכל אחד יוצא פעם בשבועיים.
- הסבב נספר מיום ראשון שלפני `--start` (או בו). עם `--start 2026-11-04`: קבוצה ב' יוצאת ב-6/11, קבוצה א' ב-13/11.
  ה-`--dry-run` מדפיס את זה.

### אילוצים

**אילוץ אחד בלבד: מי שחסום, לא יכול להגיע או לא בפול — לא זמין כלל** (לפי האקסל).

אפשר להחזיר כל אחד מהמסך ברגע שהוא מתפנה.

## איך משנים

| רוצה לשנות | איפה |
|---|---|
| אדם השתחרר / נחסם / הצטרף / עבר תא | `roster.py` — השורה שלו (`cab`, `service`, `unavailable`) |
| תקינה בתא | `CABS` בראש `build_team.py` |
| שעות המשמרות | `DAY_START`, `NIGHT_START` בראש `build_team.py` |
| שעת יציאה / חזרה ב-12/2 | `leave_time`, `return_time` ב-`CYCLE` |
| סבב 12/2 / ימים בשבוע | `CYCLE`, `RESERVE_DAYS_PER_WEEK`, `FOUR_DAYS` בראש `build_team.py` |

אחרי שינוי צריך לבנות את האימג' מחדש (שלב 1), או להעתיק רק את הקובץ לקונטיינר:

```bash
docker cp backend/magen_merkava/roster.py <container>:/app/magen_merkava/roster.py
```

> הסקריפט **פותח צוות חדש** בכל הרצה. כדי לבנות מחדש — למחוק את הצוות הקודם מקונסולת המפעיל (`/admin`),
> או להריץ עם `--name` אחר. שינויים קטנים עדיף לעשות ישר במסך הצוות.
