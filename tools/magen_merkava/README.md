# שיבוץ צוות אלחוט — מגן מרכבה

סקריפט שבונה את שיבוץ המשמרות של צוות האלחוט:
2 משמרות ביממה — **בוקר 08:00-20:00** ו-**לילה 20:00-08:00** — לכל תא לפי התקינה בלוח.

| קובץ | מה יש בו |
|---|---|
| `roster.py` | כל האנשים: תא, כשירות, רמה, הערות ואילוצים |
| `build_team.py` | הסקריפט שבונה את השיבוץ |

---

## הרצה בתוך קונטיינר (Docker, בלי compose)

אימג' ה-backend כבר כולל את כל מה שצריך (Python 3.11 + OR-Tools), אז לא צריך להתקין כלום.
כל הפקודות מתיקיית השורש של הפרויקט (`PakashAgent`).

### אפשרות א' — קונטיינר חד-פעמי (הכי פשוט)

1. לבנות את האימג' (פעם אחת, או אחרי שינוי ב-backend):

```bash
docker build -t pakash-backend ./backend
```

2. להריץ את הסקריפט:

```bash
docker run --rm -v "$PWD/tools/magen_merkava:/magen" -w /magen pakash-backend python build_team.py --start 2026-11-04 --days 7 --csv shibutz.csv
```

מה כל חלק עושה:
- `--rm` — הקונטיינר נמחק בסוף ההרצה.
- `-v "$PWD/tools/magen_merkava:/magen"` — מכניס את תיקיית הסקריפט לקונטיינר.
- `-w /magen` — מריץ מתוך התיקייה הזו.
- `python build_team.py ...` — מחליף את פקודת ברירת המחדל (השרת) בסקריפט.
- `--csv shibutz.csv` — הקובץ נשמר אצלך ב-`tools/magen_merkava/shibutz.csv` ונפתח באקסל.

> **Windows (PowerShell):** במקום `$PWD` לכתוב `${PWD}`.
> **Windows (cmd):** במקום `$PWD` לכתוב `%cd%`.

### אפשרות ב' — בתוך קונטיינר backend שכבר רץ

1. למצוא את שם הקונטיינר:

```bash
docker ps
```

2. להעתיק את הסקריפט פנימה (במקום `<container>` — השם מהעמודה NAMES):

```bash
docker cp tools/magen_merkava <container>:/magen
```

3. להריץ:

```bash
docker exec -w /magen <container> python build_team.py --start 2026-11-04 --days 7 --csv shibutz.csv
```

4. להוציא את קובץ השיבוץ החוצה:

```bash
docker cp <container>:/magen/shibutz.csv ./shibutz.csv
```

> אחרי שינוי ב-`roster.py` צריך להעתיק שוב (שלב 2).

## הרצה בלי Docker

צריך Python 3.10 ומעלה:

```bash
pip install "ortools>=9.12,<10"
cd tools/magen_merkava
python3 build_team.py --start 2026-11-04 --days 7 --csv shibutz.csv
```

## פרמטרים

| פרמטר | ברירת מחדל | הסבר |
|---|---|---|
| `--start` | מחר | תאריך היום הראשון (`YYYY-MM-DD`). המשמרת הראשונה מתחילה בו ב-08:00 |
| `--days` | 7 | לכמה ימים לבנות |
| `--full-emergency` | כבוי | לשבץ גם את מי שמגיע "רק בחירום מלא" |
| `--csv` | — | לשמור את השיבוץ לקובץ CSV |
| `--time-limit` | 30 | כמה שניות לתת לפותר |

## מה הסקריפט מדפיס

1. **שיבוץ לכל יום** — לכל משמרת ולכל תא, מי משובץ. ליד שמות מופיעות הערות כמו "צריך בכיר", "72 ש'", "לא בטוח שיגיע".
   משבצת שאין מי שימלא אותה מסומנת `<< חסרים N`.
2. **סה"כ משבצות חסרות** — לפי תא.
3. **עומס לאדם** — כמה משמרות כל אחד קיבל.
4. **לא משובצים** — מי נשאר בחוץ ולמה.

## הכללים שהסקריפט שומר עליהם

**תקינה (מלוח המשמרות, בלי כחול):**

| תא | אנשים במשמרת | משמרות ביממה |
|---|---|---|
| א', ת', מ', ח', ר' | 3 | בוקר + לילה |
| ד', ע', מרחקים | 2 | בוקר + לילה |
| התרעה | 6 | בוקר + לילה |
| רוחב | 2 | בוקר בלבד |
| ס' (סיבוב) | 3 | לילה ראשון בלבד — אחר כך עוברים לתא הבא שלהם |
| חפיפות | כולם | בוקר |

**כללים קשיחים:**
- כל אחד עובד רק בתא שלו (אנשי ס' עוברים לתא הבא אחרי הלילה הראשון).
- אין שתי משמרות ברצף (לא בוקר+לילה באותו יום, ולא לילה ואז בוקר למחרת).
- "רק 72 שעות ראשונות" — משובצים רק ב-3 הימים הראשונים.
- "שישי-שבת" — רק בשישי ובשבת.
- אמהות / אבא טרי — בלי לילות.
- לא מוסמך / לא מוכר / רמה 3 — רק כשיש באותה משמרת ובאותו תא מישהו ברמה 1-2.
- לא משובצים בכלל: חסום, לא זמין, לא בפול, מעיין, סרבנית, "רק בחירום מלא" (אלא אם `--full-emergency`).

**העדפות (הסקריפט מנסה, לא חובה):**
- לפחות אחד ברמה 1 בכל משמרת.
- חלוקה שווה של משמרות בתוך התא.
- כל אחד נשאר באותו סוג משמרת (בוקר או לילה).
- פחות שיבוצים למי שלא בטוח שיגיע או מגיע בתנאי.

## איך משנים

- **אדם השתחרר / נחסם / הצטרף** — לעדכן את השורה שלו ב-`roster.py` (להוסיף/להוריד flag, או להוסיף שורה חדשה).
- **תקינה בתא** — לשנות את `CABS` בראש `build_team.py`.
- **מה חשוב יותר** — המשקלות `W_...` בראש `build_team.py`.

הסברים על כל flag נמצאים בראש `roster.py`.
